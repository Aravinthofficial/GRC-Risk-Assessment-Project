
# GRC Risk Assessment & Compliance Tracker

## Project Overview
This project is designed to identify, assess, prioritize, and monitor information security risks using Microsoft Excel.

It helps understand basic Governance, Risk, and Compliance (GRC) activities.

## Tools Used
- Microsoft Excel
- Excel Formulas
- Charts and Dashboard

## Project Objectives
- Identify information security risks.
- Assess risks using Likelihood and Impact.
- Calculate risk scores.
- Classify risks as Low, Medium, or High.
- Recommend risk treatment actions.
- Track risk owners and remediation status.
- Monitor risks using an Excel dashboard.

## Risk Calculation
Risk Score = Likelihood × Impact

| Score | Risk Level |
|---|---|
| 1–5 | Low |
| 6–14 | Medium |
| 15–25 | High |

## Project Features
- Risk Register
- Risk Assessment
- Risk Scoring
- Risk Treatment Plan
- Residual Risk Assessment
- GRC Dashboard
- Compliance Tracking

## Sample Risk
**Risk:** Employee Laptop Malware Infection

- Likelihood: 4
- Impact: 5
- Risk Score: 20
- Risk Level: High
- Recommended Control: Endpoint Protection, EDR, and Security Awareness Training.
